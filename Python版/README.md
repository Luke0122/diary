# 日记（Python 版）

双击 `日记.exe` 或 `启动.bat` 即可打开，写日记后点右上角「导出 Word」，**内置公文排版**，保存到 `D:\日记\diary\成品\`（文件名 `日期-标题.docx`）。

## 文件说明

- `日记.exe` — 独立可执行程序（无需安装 Python，直接双击）
- `日记.pyw` — 源码（需 Python 3.11 + pywin32 + Pillow）
- `启动.bat` — 启动器（优先用 exe，否则用 .pyw）
- `data/` — 数据库、图片（首次运行自动生成）

## 功能

- 富文本编辑：标题 + 正文 + 加粗 / 斜体 / 下划线 + 插入图片（选中文字后点 B/I/U）
- 按日期新建/查看/编辑/删除，列表视图 + 日历视图
- 自动保存（停止输入 5 秒）
- 搜索（关键词）
- 统计（总篇数 / 连续天数 / 累计字数）
- 导出 Word（内置公文排版）：
  - 页边距 2.5cm
  - 标题（日期+标题）黑体 22pt 居中
  - 正文宋体 12pt（小四）两端对齐，首行缩进 2 字符，1.5 倍行距
  - 小标题（一、/ 二、/ 1. 等）黑体 12pt 顶格

## 从源码运行

```
pip install pywin32 pillow
pythonw 日记.pyw
```

## 重新打包 exe

修改 `日记.pyw` 后需用 miniconda 环境重新打包（含 conda 的 DLL 依赖），打包命令见项目工作日志。
